# Claude Code 跑马灯 🏃‍♂️✨

VS Code 扩展,监听 Claude Code 所有工作区的会话状态,在**悬浮小窗**里用流动灯带实时呈现。支持多会话、自动启动,不占编辑区。

![效果](https://img.shields.io/badge/Windows-WinForms-blue)

## 使用

安装后**自动运行**(无需任何操作)。有活跃 Claude 会话时,悬浮窗自动出现在屏幕左上角。

- **多会话**:每个工作区一行,显示状态和项目名
- **拖动**:左键拖动悬浮窗到任意位置
- **关闭**:右键关闭悬浮窗
- **手动重启**:`Ctrl+Shift+P` → `Claude Code 跑马灯: 打开面板`

## 状态与灯效

| 状态 | 灯效 | 颜色 |
|------|------|------|
| 🤔 思考中 | 蓝色流光 | `#388BFD` |
| 🔧 执行工具 | 琥珀旋转 | `#FB923C` |
| 💬 等待输入 | 翠绿呼吸 | `#34D399` |
| ❌ 出错 | 红色闪烁 | `#F87171` |
| 💤 空闲 | 青色微光 | `#22D3EE` |

## 原理

1. 轮询 `~/.claude/projects/*/*.jsonl`,按 `cwd`(工作区目录)分组
2. 对每个工作区,取最近会话的事件序列,用状态机推断瞬时状态(思考/执行/等输入/出错/空闲)
3. 状态写入文件,独立 WinForms 小窗轮询读取并驱动灯带动画

组件:
- `sessionManager.ts` — 扫描所有会话,按工作区分组合并状态
- `stateMachine.ts` — 事件序列 → 瞬时状态(纯函数)
- `windowManager.ts` — 管理悬浮窗进程
- `window/MarqueeForm.cs` — 悬浮窗 C# WinForms 界面(抗锯齿自绘)

## 系统要求

- Windows 10/11
- VS Code 1.74+
- Claude Code(需登录)
- .NET Framework 4.5+(Windows 自带)

## 隐私

- **不联网**:所有数据在本地处理
- **不修改**:只读 Claude Code 的日志文件,不做任何写入
- **不持久**:关闭扩展后清理临时状态文件
